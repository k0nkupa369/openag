## UI work skills

For any desk UI work (building, fixing or reviewing UI, including rendered acceptance), always use these skills:

- `shadcn`: invoke it from `apps/desk`. From the repo root its `npx shadcn info` preload fails with `monorepo_root`. Its rules are the composition checklist (base-nova, Base UI `render`, semantic tokens, the Base UI toast rule).
- `emil-design-eng`: craft and interaction polish. Report review findings in its Before | After | Why table.
- `find-animation-opportunities` and `improve-animations`: read-only motion audits that propose and plan motion changes.
- `gestures`: drag, swipe, sheet and other touch interactions.

Load `shadcn` and `emil-design-eng` before starting. Run the motion and gesture skills as a pass after the visual work.
